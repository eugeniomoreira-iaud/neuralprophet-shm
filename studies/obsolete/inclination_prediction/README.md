# Study · Predicting the inclination from the extended sensor package

Three questions about the 20-column package installed at station 02 on
2025-02-21, asked of the **compensated** inclination on a **1-hour** grid:

1. Can one sensor channel predict the inclination, and which is best?
2. Can a combination beat the best single channel, and how is that diagnosed?
3. How far ahead can NeuralProphet forecast, and with what uncertainty?

**The complete evaluation — operator scans, rankings, subset search,
diagnostics, horizon curves, calibration, figures, interpretation and verdicts
— is in
[`report/inclination_prediction_report.pdf`](report/inclination_prediction_report.pdf).**
This file only says how to run and rebuild things.

## Premises

This study deliberately accepts what `../thermal_compensation/` tested and
rejected, in order to ask a different question on top of it:

| Premise | Consequence |
|---|---|
| The logged `I` channel is an inclination in millidegrees | The 2500 offset the sibling study subtracts is added back. Nothing downstream changes — the compensation normalises the series to start at zero. |
| The documented compensation is correct | `inc_comp` is the target of every model. The coefficient is never swept. |
| The grid is one hour | Matches the rate of every external proxy the pipeline aligns against. |

The second premise has a consequence that governs how every result is read, and
the report states it before any number: the compensation subtracts 5 mdeg per
degree of air temperature, so air temperature predicts the *residual of the
correction* as much as it predicts the structure.

## Sign convention and the lag bound

The wall is an embankment. The **valley side** is the more sun-exposed, expands
further under daytime heating, and tips the wall **towards the mountain** — a
**negative** change by the instrument's convention. A negative correlation
between the inclination and a heating driver is therefore the *expected* result
at this site, not an anomaly. Lags beyond **12 hours** are not physically
expected, so the operator scan is bounded there; past half a diurnal cycle a
delay of `d` hours is indistinguishable from a lead of `24 − d`, and an
unbounded scan returns aliased leads. Bounding the scan changed the answer —
wall temperature's `R²` fell from 0.636 to 0.459 and it left every winning
subset.

Step 4b tests the expected sign on the **raw** channel and finds the opposite:
`r(inc, tair) = +0.845` at `+1.63 mdeg/°C`. The compensated series shows the
expected negative sign only because 5 is subtracted from 1.63. The full record
of this contradiction, and the three readings consistent with it, is in
[`docs/raw-data-format.md`](../../docs/raw-data-format.md) Section 7.5.

The 12-hour bound applies to the **external forcings** (`tair`, `sr`), which must
causally precede the response. **`twall` is exempt** — it is an internal state
variable at an unknown depth, so it may legitimately lag the deformation. Step 5b
scans it over *signed* delays as a diagnostic: the inclination **leads** the probe
by 2 h on both the raw and the compensated channel, and the signed optimum is
−4 h at `R² = 0.797` against 0.491 causal. That is the signature of a **deep**
probe. The lead is clamped to zero by `operators_from_summary(causal_only=True)`
before any predictive feature is built, so Step 5b changes no model result —
verified by a byte-for-byte diff of all thirteen predictive tables.

## Reproducing the study

```bash
conda activate neuralprophet_env
cd studies/inclination_prediction
jupytext --to ipynb inclination_prediction_study.py
jupyter nbconvert --to notebook --execute --inplace inclination_prediction_study.ipynb
```

The first run copies 416 files out of the read-only Google Drive archive, which
takes about forty minutes at the observed streaming rate; if
`../thermal_compensation/.cache/` is already populated, copying it across is
instant and covers the same date range. Later runs reuse `.cache/`. The
NeuralProphet stage dominates the remaining runtime — set
`RUN_NEURALPROPHET = False` in the parameter cell to skip it.

**Figures.** All plotting goes through seaborn; set `CONTEXT = 'paper'` in the
parameter cell to re-export every figure at manuscript column size.

## Rebuilding the report

Run the notebook first — the report reads the figures from `outputs/`, which is
not committed.

```bash
cd report
pdflatex inclination_prediction_report.tex   # twice, for the table of contents
```

The shared preamble lives in `../../_shared/reportstyle.tex` and stays inside
the package set shipped with a basic TeX Live installation.
