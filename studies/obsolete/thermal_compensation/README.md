# Study · Is the documented temperature compensation good for the prediction system?

Self-contained investigation of one preprocessing decision: the fixed thermal
correction that `00_Sensor_Preprocessing` applies to the inclinometer signal before any
other stage sees it, evaluated on the current instrument era of station 02.

```
I_comp(t) = I(t) − (T_air(t) − T_air(t₀)) · c · 1000,     c = 0.005
```

**The complete evaluation — results, figures, interpretation, verdict and caveats — is
in [`report/thermal_compensation_report.pdf`](report/thermal_compensation_report.pdf).**
This file only says how to run and rebuild things.

**Verdict in one line:** the correction fails all three acceptance criteria. The fitted
thermal slope of this instrument is 1.63 mdeg/°C against the 5.0 applied, and every raw
configuration outperforms every compensated one under both models tested. A companion
study on the legacy era, `../thermal_compensation_legacy/`, reaches the same verdict
from independent data.

**On the "instantaneous" premise.** The study also tests whether the structure responds
without delay, since a body with thermal mass cannot. Solar radiation acts through a
2–4 hour thermal lag (explained variance 0.575 → 0.731 on the diurnal band); air
temperature acts with no lag at all, because it is itself an already-integrated proxy
for the same forcing. Neither finding rescues the correction, which fails on magnitude
rather than on timing.

**Sampling.** Everything runs on a **1-hour grid**, matching the rate of every external
proxy the pipeline aligns against. The native 20-minute record is kept only for one
sub-hourly lag check.

**Figures.** All plotting goes through seaborn. Set `CONTEXT = 'paper'` in the parameter
cell to re-export every figure at manuscript column size — seaborn rescales the
typography and the shared canvas scale rescales the figures.

## Reproducing the study

```bash
conda activate neuralprophet_env
cd studies/thermal_compensation
jupytext --to ipynb thermal_compensation_study.py
jupyter nbconvert --to notebook --execute --inplace thermal_compensation_study.ipynb
```

The first run copies 416 files out of the read-only Google Drive archive, which takes
about forty minutes at the observed streaming rate. Later runs reuse `.cache/` and
complete in a few minutes plus NeuralProphet training time.

## Rebuilding the report

Run the notebook first — the report reads the figures from `outputs/`, which is not
committed.

```bash
cd report
pdflatex thermal_compensation_report.tex   # twice, for the table of contents
```

The shared preamble lives in `../../_shared/reportstyle.tex` and stays inside the
package set shipped with a basic TeX Live installation.
