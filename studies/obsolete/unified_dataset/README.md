# Study · The unified dataset, and what imputation can do for it

The whole archive in one place — all three legacy stations, both instrument
eras, **2018-07-26 to 2026-08-13** — cleaned, compensated, provenance-labelled;
then a study of what is missing from it, what can be filled, and how long a
continuous stretch that buys.

**The complete evaluation is in
[`report/unified_imputation_report.pdf`](report/unified_imputation_report.pdf).**
This file only says how to run and rebuild things.

## Two notebooks, and why they are separate

| Notebook | Role |
|---|---|
| `build_unified_dataset.py` | **The ingest.** The only place in the project that reads the raw archive. Re-run it whenever the archive grows. |
| `imputation_study.py` | **The study.** Consumes the ingest's output and never touches an `.adc` file. |

The split is not tidiness. The ingest writes **only measurements** — every row it
writes carries `inc_source = observed`. Imputation happens on the far side of
that boundary, so a filled value can never be mistaken for a reading by a
notebook three steps downstream.

The ingest discovers the archive extent itself, so adding new days needs no
edit: run it again.

## What the ingest produces

One CSV per station on the hourly grid, in `data/interim/unified/`, plus
`unified_manifest.json` recording the build.

| Column | Meaning |
|---|---|
| `batt`, `tair`, `rh` | Supply voltage, air temperature, relative humidity |
| `inc` | Inclinometer, mdeg about the instrument's calibrated zero. **Its absolute level carries no structural information** |
| `sr`, `twall` | Solar radiation, wall temperature. Current era, station 02 only |
| `inc_comp` | Compensated at the documented coefficient, anchored **within each era separately** |
| `inc_comp_joined` | The same with the estimated instrument offset removed. Station 02 only. **Carries an estimated constant** |
| `era`, `instrument` | Which era, and which physical instrument |
| `inc_source` | `observed` or `missing` — the ingest fills nothing |
| `station` | Station identifier |

## Three rules the dataset obeys

**The two eras are two instruments.** The package installed on 2025-02-21
replaced the legacy network; its inclinometer shares no baseline with legacy
block b2 (`docs/raw-data-format.md` §3.3). The primary columns keep the
baselines apart. A single continuous series exists only as `inc_comp_joined`,
named so that nobody uses it by accident.

**The absolute level means nothing.** Only changes carry structural information
(§7.1). Every level here is referred to an arbitrary anchor.

**A filled value is not a measurement.** Provenance survives into every product.

## What the study found

- **The network failed in stages.** Station 01 stopped in June 2022 and station
  03 in June 2023 — years before the February 2025 replacement. There was no
  three-station network for most of the archive.
- **Every channel fails at once.** On 100 % of the missing hours, every other
  channel is missing too. This is outage-driven missingness, and it means **no
  covariate-conditioned method can fill a real gap here.**
- **The benchmark cannot see that.** Injected gaps have their drivers intact, so
  a driver-based filler scores best at almost every length. It is measured and
  then explicitly refused; the gap between its score and its availability is the
  study's clearest argument for an availability criterion.
- **A constant does not reconcile the two instruments.** The step at the
  changeover is −132.5 mdeg, but the diurnal amplitude rises by 34 % across it.
  The instruments differ in gain as well as zero.

## Reproducing

```bash
conda activate neuralprophet_env
cd studies/unified_dataset

jupytext --to ipynb build_unified_dataset.py
jupyter nbconvert --to notebook --execute --inplace build_unified_dataset.ipynb

jupytext --to ipynb imputation_study.py
jupyter nbconvert --to notebook --execute --inplace imputation_study.ipynb
```

**The ingest must run first** — the study reads its output and nothing else.

The cache holds 2345 files. Populating it from scratch takes hours at the
observed Drive streaming rate; copying the sibling studies' `.cache/`
directories across first covers almost all of them instantly.

**Figures.** All plotting goes through seaborn; set `CONTEXT = 'paper'` to
re-export at manuscript column size.

## Rebuilding the report

Run both notebooks first — the report reads figures from `outputs/`, which is
not committed.

```bash
cd report
pdflatex unified_imputation_report.tex   # twice, for the ToC
```

The shared preamble is `../../_shared/reportstyle.tex` and stays inside the
package set shipped with a basic TeX Live installation.
